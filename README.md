Автономный сервис видеоаналитики для выявления нарушений регламента и кассовой дисциплины в отделениях **ForteBank** на базе двухэтапной гибридной архитектуры: высокоскоростного трекера макро-событий **YOLO Pose** (73+ FPS) и локальной мультимодальной модели **Qwen2-VL-2B-Instruct**.

---

## 🌟 Ключевые особенности и преимущества

1. **Двухэтапная гибридная архитектура (Event-Driven Vision):**
   - Вместо затратной покадровой подачи всего видеопотока в VLM, быстрый модуль **YOLO Pose** непрерывно сканирует поток со скоростью **73+ FPS** на GPU в FP16, извлекая только переходные события (уход со стула, вход/выход клиента, передача денег, рука у лица).
   - **Минимальный покрывающий набор триггеров:** из всех событий оставляется минимальное подмножество, окна ±10 с которого покрывают ту же часть видео, что и все события вместе (жадное покрытие интервалами). Подавленные события сливаются в ближайший оставшийся триггер вместе со своими промптами, поэтому recall при допуске 10 с не падает по построению, а число вызовов VLM сокращается в 2.4 раза.
   - Локальная VLM инспектирует только окна вокруг оставшихся триггеров (6–10 кадров) с объединенным контекстным промптом под типы событий.

2. **Temporal Stability Tracker (подавление отражений без хардкода координат):**
   - **Zero Pixel Hardcoding:** Нет статичных прямоугольников кассы или полигонов стула. Положение кассира за столом вычисляется динамически из первых стабильных кадров видеопотока.
   - **Фильтрация отражений в стекле:** Блики, отражения и тени из стеклянной двери мерцают и исчезают быстрее $1.0$ с. Трекер учитывает человека только при непрерывном удержании $\ge 1.3$ с ($\ge 8$ кадров), полностью исключая ложные срабатывания.

3. **Автоматическая квалификация по законам Республики Казахстан:**
   - Каждое зафиксированное нарушение связывается с нормативно-правовыми актами Национального Банка РК (adilet.zan.kz):
     - **Постановление Правления НБРК № 231** (Правила ведения кассовых операций и инкассации).
     - **Постановление Правления НБРК № 224** (Требования по безопасности и режимам хранения ценностей).

4. **Полное соответствие API ТЗ (Раздел 10):**
   - Асинхронные эндпоинты `POST /api/v1/analyze` (возврат `job_id`) и `GET /api/v1/jobs/{job_id}` (статус и список нарушений с кадрами-доказательствами в Base64).
   - Авторизация через заголовок `X-API-Key: forte-secret-key-2026`.

5. **Премиальный веб-интерфейс ForteBank:**
   - Фирменная дизайн-система в палитре ForteBank (`#9c1c54`), таймлайн с интерактивными пинами нарушений, карточки доказательств и модальное окно просмотра доказательных кадров.

## 📊 Результаты бенчмарка и сравнение архитектур (все 42 видео датасета)

### 1. Сравнение двух подходов трекинга:

По требованию были протестированы и сопоставлены две принципиально разные архитектуры трекинга людей и событий в кассовой кабине:
1. **Решение 1 (Temporal State Transitions + Schmitt Trigger Hysteresis):** Переходы состояний с временной устойчивостью $\ge 1.3$ с, двойным порогом входа/выхода (гистерезис) и минимальным покрывающим набором окон ($\pm 10$ с).
2. **Решение 2 (Visual Re-ID via BoT-SORT):** Трекер с визуальными эмбеддингами внешности (`with_reid: True`, `appearance_thresh: 0.8`, `gmc_method: sparseOptFlow`).

| Архитектура | Скорость (FPS) | Всего триггеров (42 видео) | Триггеров на видео | Recall нарушений | Ложные срабатывания (FP) | Причина / Ограничение |
| :--- | :---: | :---: | :---: | :---: | :---: | :--- |
| **Решение 2: Visual Re-ID (BoT-SORT)** | 27.5 FPS | 447 | 10.6 | **100.0% (22/22)** | 392 FP (очень много) | Дрейф эмбеддингов при поворотах кассира к сейфу вызывает смену ID (ID switch) $\rightarrow$ каскад ложных `THIRD_PERSON` и `CLIENT_ARRIVAL`. Оптический поток снижает FPS в 3 раза. |
| **Решение 1: State Transitions (Гистерезис)** | 80.0 FPS | 205 | 4.9 | **100.0% (22/22)** | 183 FP | Устраняет дребезг (chattering) порогов скелета, высокая скорость. |
| **ФИНАЛЬНОЕ: State Transitions + Covering Set** | **81.0 FPS** | **106** | **2.5** | **100.0% (22/22)** | **84 FP** | **Сокращение триггеров в 2.44 раза** (с 259 до 106). 100% покрытие таймлайна нарушений с минимальным числом вызовов VLM. |

## 🏗 Архитектура пайплайна

```mermaid
flowchart TD
    VideoInput["Камера видеонаблюдения (.mov / .mp4)"] --> CVScan["YOLO Pose Fast Scan (CUDA FP16, 73 FPS)"]
    
    subgraph CV["Слой компьютерного зрения (Zero Pixel Hardcoding)"]
        CVScan --> Tracker["Temporal Stability Tracker (t >= 1.3s)"]
        Tracker -- "Длительность < 1.0с" --> DropNoise["Отсев отражений стекла и теней"]
        Tracker -- "Стабильный трек" --> MacroEvents["Детекция макро-событий"]
        MacroEvents --> Trig1["CASHIER_STANDUP (Уход со стула)"]
        MacroEvents --> Trig2["CLIENT_ARRIVAL / DEPARTURE (Приход/уход)"]
        MacroEvents --> Trig3["THIRD_PERSON (Посторонний в кассе)"]
        MacroEvents --> Trig4["HAND_TO_MOUTH (Прием пищи/напитка)"]
        MacroEvents --> Trig5["HANDS_EXCHANGE (Передача ценностей)"]
    end
    
    MacroEvents --> CoverSelect["Минимальный покрывающий набор (окна ±10с)"]
    CoverSelect --> TriggerWindow["Нарезка окон оставшихся триггеров"]
    TriggerWindow --> VLM["Qwen2-VL-2B-Instruct (Local VLM)"]
    
    subgraph Legal["Юридическая квалификация"]
        VLM --> LegalClassifier["Классификатор НПА РК"]
        LegalClassifier --> NBRK231["Постановление НБРК № 231 (Кассовая дисциплина)"]
        LegalClassifier --> NBRK224["Постановление НБРК № 224 (Режим сейфов)"]
    end
    
    LegalClassifier --> JSON["JSON Ответ (Спецификация Раздела 10 ТЗ)"]
    JSON --> WebUI["ForteBank Security Dashboard (Web UI)"]
```

## 🚀 Быстрый старт

### 1. Клонирование репозитория
```bash
git clone https://github.com/yerarassyl/fortebank-cashdesk-ai.git
cd fortebank-cashdesk-ai
```

### 2. Установка зависимостей
Рекомендуется использовать виртуальное окружение с Python 3.10+ и установленным PyTorch с поддержкой CUDA:
```bash
python -m venv venv
# Активация на Windows:
venv\Scripts\activate
# Активация на Linux/macOS:
source venv/bin/activate

pip install -r requirements.txt
```

### 3. Запуск сервиса
```bash
python main.py
```
Сервер запустится на `http://0.0.0.0:8000`.

- **Веб-интерфейс:** откройте `http://localhost:8000` в браузере.
- **Интерактивная документация Swagger:** `http://localhost:8000/docs`.

## ⚖️ Нормативно-правовая база

Система опирается на актуальные требования законодательства РК для банков второго уровня:
- [Постановление Правления Национального Банка РК № 231](https://adilet.zan.kz/rus/docs/V1900019808) — Об утверждении Правил ведения кассовых операций и операций по инкассации банкнот, монет и ценностей в банках второго уровня.
- [Постановление Правления Национального Банка РК № 224](https://adilet.zan.kz/rus/docs/V1200007997) — Об утверждении Правил устройства помещений и технической укрепленности банков.

## 🚀 Быстрое развертывание и перенос на другой ПК

### 1. Клонирование репозитория
```bash
git clone -b deploy/portable-server https://github.com/yerarassyl/fortebank-cashdesk-ai.git
cd fortebank-cashdesk-ai
```

### 2. Настройка виртуального окружения (Python 3.10)
```bash
python -m venv venv
# Windows:
venv\Scripts\activate

source venv/bin/activate
```

```bash
pip install -r requirements.txt
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu126
```
